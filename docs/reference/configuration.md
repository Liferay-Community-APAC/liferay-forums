# Configuration Reference

To change a setting, edit the page, select the fragment, and open its configuration in the sidebar.

## Home Page Hero

| Setting | Default |
| --- | --- |
| Hero Title | Liferay Forums |
| Hero Description | Find answers, ask questions, and join the discussion. |
| Show Solutions, Show Discussions, Show Messages | On |
| Show New Discussion Button | On |

## Category Grid

| Setting | Default |
| --- | --- |
| Max Categories to Show | 12 |

## Discussions List

| Setting | Default |
| --- | --- |
| Messages Per Page | 20 |
| Show Search Bar | On |

## Topic Page

| Setting | Default |
| --- | --- |
| Replies Per Page | 10 |
| Max Related Topics | 5 |

## New Discussion and Reply Form

| Setting | Default |
| --- | --- |
| Form Mode | Modal |

## Forum Categories Admin

The names, descriptions, and external reference codes of the four categories that **Seed Default Categories** adds.

## Languages

The forum's labels are translated into Arabic, Catalan, Chinese (Simplified), Dutch, English, Finnish, French, German, Hungarian, Japanese, Portuguese (Brazil), Spanish, and Swedish. Notification templates and page names are in English; translate them in Liferay.
