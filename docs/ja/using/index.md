# フォーラムの使い方 {#using-the-forum}

サインインしたメンバーは、フォーラムを閲覧し、ディスカッションを開始し、返信、投票、トピックのフォロー、コンテンツの報告ができます。管理者は、[サインインしていない訪問者がフォーラムを閲覧できるようにする](../reference/roles-and-permissions.html#let-guests-read-the-forum)こともできます。

<div class="doc-cards">
  <a class="card doc" href="browsing-and-searching.html"><strong>閲覧と検索</strong><span>カテゴリー、タグ、アクティビティ、キーワードでディスカッションを見つけます。</span></a>
  <a class="card doc" href="starting-a-discussion.html"><strong>ディスカッションの開始</strong><span>新しいトピックや質問を投稿します。</span></a>
  <a class="card doc" href="replying.html"><strong>返信とメンション</strong><span>会話に参加し、@ で他の人を呼び込みます。</span></a>
  <a class="card doc" href="questions-and-answers.html"><strong>質問と回答</strong><span>質問を解決した返信をマークします。</span></a>
  <a class="card doc" href="voting.html"><strong>投票</strong><span>トピックや返信に賛成票または反対票を投じます。</span></a>
  <a class="card doc" href="subscriptions-and-notifications.html"><strong>購読と通知</strong><span>トピックをフォローし、返信の通知を受け取ります。</span></a>
  <a class="card doc" href="reporting.html"><strong>コンテンツの報告</strong><span>コミュニティのルールに違反する投稿を報告します。</span></a>
</div>
