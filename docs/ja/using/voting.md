# 投票 {#voting}

投票によって、コミュニティが最も役に立つと考えるトピックや返信がわかります。

- 賛成票を投じるには **thumbs up** を、反対票を投じるには **thumbs down** をクリックします。その間の数字が合計です。
- 同じボタンをもう一度クリックすると投票を取り消し、もう一方のボタンをクリックすると投票を変更します。
- トピックと各返信に投票できます。
