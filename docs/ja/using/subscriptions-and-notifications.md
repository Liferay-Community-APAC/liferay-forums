# 購読と通知 {#subscriptions-and-notifications}

トピックをフォローすると、新しい返信があるたびに通知が届きます。

## トピックをフォローする {#following-a-topic}

- トピックを開始するときは **Subscribe to This message** がチェックされているため、自分のトピックはフォローされます。
- 他のトピックをフォローするには、その **Options** メニュー（⋮）を開き、**Subscribe** をクリックします。フォローをやめるには **Unsubscribe** をクリックします。

## 通知される内容 {#what-youre-notified-about}

| イベント | 通知される人 |
| --- | --- |
| 新しい返信 | トピックをフォローしている全員（返信の投稿者を除く） |
| メンション | メンションされた人（返信の通知をすでに受け取る場合を除く） |
| 新しいメンションを含む返信の編集 | 新しくメンションされた人のみ |

通知は、Liferay の通知メニューとメールで届きます。メールには、返信の冒頭部分と **View the discussion** リンクが含まれます。

{: .note }
メール通知は、管理者が設定して初めて機能します。[メール通知](../administering/email-notifications.html)を参照してください。
