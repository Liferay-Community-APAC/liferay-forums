# 管理 {#administering}

サイト管理者は、フォーラムのカテゴリー、通知、外観、サイトを設定し、フォーラムを形づくります。

<div class="doc-cards">
  <a class="card doc" href="categories.html"><strong>カテゴリーの管理</strong><span>カテゴリーとサブカテゴリーを作成、編集、削除します。</span></a>
  <a class="card doc" href="email-notifications.html"><strong>メール通知</strong><span>サイトが所有するアドレスから通知を送信します。</span></a>
  <a class="card doc" href="customizing.html"><strong>フォーラムのカスタマイズ</strong><span>色、ヘッダーとフッター、ホームページ、注目のディスカッション。</span></a>
  <a class="card doc" href="several-sites.html"><strong>複数のフォーラムサイトの運用</strong><span>製品、地域、チームごとに別々のフォーラムを運用します。</span></a>
</div>
