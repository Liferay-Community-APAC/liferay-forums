# 設定リファレンス {#configuration-reference}

設定を変更するには、ページを編集し、フラグメントを選択して、サイドバーでその設定を開きます。

## ホームページのヒーロー {#home-page-hero}

| 設定 | デフォルト |
| --- | --- |
| Hero Title | Liferay Forums |
| Hero Description | Find answers, ask questions, and join the discussion. |
| Show Solutions、Show Discussions、Show Messages | オン |
| Show New Discussion Button | オン |

## カテゴリーグリッド {#category-grid}

| 設定 | デフォルト |
| --- | --- |
| Max Categories to Show | 12 |

## ディスカッション一覧 {#discussions-list}

| 設定 | デフォルト |
| --- | --- |
| Messages Per Page | 20 |
| Show Search Bar | オン |

## トピックページ {#topic-page}

| 設定 | デフォルト |
| --- | --- |
| Replies Per Page | 10 |
| Max Related Topics | 5 |

## 新規ディスカッションと返信のフォーム {#new-discussion-and-reply-form}

| 設定 | デフォルト |
| --- | --- |
| Form Mode | Modal |

## Forum Categories Admin {#forum-categories-admin}

**Seed Default Categories** で追加される 4 つのカテゴリーの名前、説明、外部参照コード。

## 言語 {#languages}

フォーラムのラベルは、アラビア語、カタルーニャ語、中国語（簡体字）、オランダ語、英語、フィンランド語、フランス語、ドイツ語、ハンガリー語、日本語、ポルトガル語（ブラジル）、スペイン語、スウェーデン語に翻訳されています。通知テンプレートとページ名は英語です。Liferay で翻訳してください。
