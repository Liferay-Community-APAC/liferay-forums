# 優先度によるトピックの固定 {#pinning-topics-with-priority}

優先度を設定すると、トピックはディスカッションの一覧の上部、優先度のないすべてのトピックより上に表示され、バッジが付きます。

| 優先度 | 用途 |
| --- | --- |
| **Urgent** | 障害など、緊急性の高いお知らせ。最初に表示されます。 |
| **Sticky** | FAQ など、表示し続けるべきトピック。 |
| **Announcement** | ニュースやコミュニティのお知らせ。 |
| **None** | 通常のトピック。 |

モデレーターは、トピックを[開始](../using/starting-a-discussion.html)または編集するときに、**Priority** フィールドで優先度を設定します。メンバーにはこのフィールドは表示されません。他の人がトピックの優先度を変更した場合は、元に戻されます。
