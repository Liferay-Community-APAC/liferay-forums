# Pinning Topics with Priority

A priority keeps a topic at the top of the discussions list, above all topics without one, and labels it with a badge.

| Priority | Use It For |
| --- | --- |
| **Urgent** | Time-critical notices, such as an outage. Listed first. |
| **Sticky** | Topics that should stay visible, such as a FAQ. |
| **Announcement** | News and community announcements. |
| **None** | Regular topics. |

Moderators set the priority in the **Priority** field when they [start](../using/starting-a-discussion.html) or edit a topic. Members don't see this field. If anyone else changes a topic's priority, it's changed back.
