# Using the Forum

Signed-in members can read the forum, start discussions, reply, vote, follow topics, and report content. An administrator can also [let signed-out visitors read the forum](../reference/roles-and-permissions.html#let-guests-read-the-forum).

  <a class="card doc" href="reporting.html"><strong>Reporting Content</strong><span>Flag posts that break the community rules.</span></a>
