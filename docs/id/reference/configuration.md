## Forum Categories Admin {#forum-categories-admin}

Nama, deskripsi, dan external reference code dari keempat kategori yang ditambahkan oleh **Seed Default Categories**.

## Bahasa {#languages}

Label forum diterjemahkan ke dalam bahasa Arab, Katalan, Tionghoa (Sederhana), Belanda, Inggris, Finlandia, Prancis, Jerman, Hungaria, Jepang, Portugis (Brasil), Spanyol, dan Swedia. Notification template dan nama halaman berbahasa Inggris; terjemahkan di Liferay.
