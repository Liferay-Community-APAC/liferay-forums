# Pemberian Suara {#voting}

Suara menunjukkan topik dan balasan mana yang dianggap paling bermanfaat oleh komunitas.

- Klik **thumbs up** untuk memberi suara naik (upvote), atau **thumbs down** untuk memberi suara turun (downvote). Angka di antara keduanya adalah totalnya.
- Klik tombol yang sama sekali lagi untuk menghapus suara Anda, atau tombol lainnya untuk mengubahnya.
- Anda dapat memberi suara pada topik dan pada setiap balasan.
