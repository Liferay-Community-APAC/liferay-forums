# Menggunakan Forum {#using-the-forum}

Anggota yang sudah masuk dapat membaca forum, memulai diskusi, membalas, memberi suara, mengikuti topik, dan melaporkan konten. Administrator juga dapat [mengizinkan pengunjung yang belum masuk membaca forum](../reference/roles-and-permissions.html#let-guests-read-the-forum).
