# Menyematkan Topik dengan Prioritas {#pinning-topics-with-priority}

Prioritas membuat sebuah topik tetap berada di bagian atas daftar diskusi, di atas semua topik tanpa prioritas, dan memberinya label berupa lencana.

| Prioritas | Gunakan Untuk |
| --- | --- |
| **Urgent** | Pemberitahuan yang mendesak, seperti gangguan layanan. Dicantumkan pertama. |
| **Sticky** | Topik yang harus tetap terlihat, seperti FAQ. |
| **Announcement** | Berita dan pengumuman komunitas. |
| **None** | Topik biasa. |

Moderator mengatur prioritas di kolom **Priority** saat mereka [memulai](../using/starting-a-discussion.html) atau mengedit topik. Anggota tidak melihat kolom ini. Jika orang lain mengubah prioritas topik, prioritas tersebut akan dikembalikan.
