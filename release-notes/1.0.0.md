First release of Liferay Forums, for Liferay DXP 2026.Q1 LTS with the [required Liferay fixes](https://liferay-community-apac.github.io/liferay-forums/installing/#required-liferay-fixes).

**Install:** follow [Installing](https://liferay-community-apac.github.io/liferay-forums/installing/). Deploy the zips in this order: the batch, then the microservice, then the site initializer.

| File | What It Is |
| --- | --- |
| `liferay-forums-batch.zip` | The forum's data model, notification templates, and search blueprint |
| `liferay-forums-etc-spring-boot.zip` | The forum's microservice: bans, topic locks, notifications, and activity dates |
| `liferay-forums-site-initializer.zip` | Creates the forum site **FORUMS**, at `/web/forums` |
| `generate-site-initializer-zips.sh` | On Liferay Self-Hosted, makes one site initializer zip per site, for several forum sites |
| `liferay-forums-1.0.0-source.zip` | The source of the three zips, as a Liferay Workspace: for Liferay PaaS, for more forum sites, and for your own workspace |
| `SHA256SUMS` | Checksums of the files above |

### Included

- Discussion forums for Liferay DXP: topics and replies, questions and answers, categories, mentions, follows with web and email notifications, voting, topic locks, reports, per-site bans, search, and promoted discussions.
- Several forum sites on one Liferay instance, each with its own categories, topics, and bans.
- Labels in 13 languages.

See [Known Issues](https://liferay-community-apac.github.io/liferay-forums/reference/known-issues.html) for the limitations of this release.
